# Alatau Air Cargo — сайт

Статический сайт грузовой авиакомпании Alatau Air Cargo (хаб — аэропорт «Сары-Арка», Караганда).
Без сборки и зависимостей: достаточно открыть `index.html` или выложить папку на любой хостинг (GitHub Pages, Vercel, Netlify, nginx).

## Что внутри

| Раздел | Что делает |
|---|---|
| Глобус (Fig 1) | 3D-глобус на three.js: свечение атмосферы, «кометы» по всем маршрутам из KGF, пульсация хаба, звёзды. Тянется мышью/пальцем, стрелками. |
| Флот (Fig 2) | 3D-модели A340-600 и 777F на поворотном столе: тени, ливрея с логотипом на киле, вращающиеся вентиляторы, навигационные огни и стробы, открытие люка и погрузка 8 ULD, режимы камеры. |
| Сеть (Fig 3) | Карта Natural Earth с ортодромиями, расчёт расстояния и времени в пути. |
| Калькулятор | Платный вес по стандарту IATA (делитель 6000), объём, плотность, оценка числа паллет PMC; результат переносится в форму запроса. |
| Запрос | Форма открывает почтовую программу с готовым письмом на адрес отдела продаж. |
| Фон сайта | Кнопка «Фон» (справа внизу и в шапке): 7 готовых тем, свой цвет, 4 пейзажа, загрузка своего фото с регулировкой затемнения. Выбор сохраняется в браузере посетителя. |

## Перед публикацией

Замените контакты-заглушки в начале `assets/js/app.js`:

```js
const CONFIG={
  email:'sales@example.com',
  phone:'+7 (700) 000-00-00',
  hours:'Пн–Пт, 09:00–18:00 (UTC+5)'
};
```

## Превью ссылки (баннер)

`og-image.jpg` (1200×630) показывается, когда ссылку на сайт пересылают в Telegram, WhatsApp, Facebook и т. п.
Мессенджерам нужен полный адрес картинки: в `index.html` стоит `https://alataucargo.vercel.app/` — если домен на Vercel другой, замените его в метатегах `og:url`, `og:image`, `twitter:image`.

## Структура

```
index.html               страница
assets/css/main.css      стили, палитры тем фона
assets/js/theme.js       переключатель фона (грузится в <head>, без мигания)
assets/js/app.js         карта, 3D, калькулятор, форма
assets/js/geo.js         данные карты и глобуса (Natural Earth)
assets/vendor/three.min.js  three.js r128 (MIT)
assets/img/              логотип: logo.svg (полный), logo-mark.svg (знак), favicon.svg
```

## Логотип

Знак — круг-глобус, силуэт гор Алатау со снежной вершиной, ортодромия от золотой точки-хаба и самолёт, выходящий за рамку.
Цвета: графит `#18181a`, небесный `#0090ad` / `#3fc6de`, золото `#e2a93b`. В разметке знак берёт цвета из CSS-переменных и меняется вместе с темой фона.

## Добавить свою тему фона

1. В `assets/css/main.css` добавьте блок `:root[data-bg=myid]{ --page:…; --card:…; … }` (по образцу `night` или `steppe`).
2. В `assets/js/theme.js` добавьте пресет в массив `PRESETS` (`id`, `name`, `tone: 'dark'|'light'` и цвета превью).
